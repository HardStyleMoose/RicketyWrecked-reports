# RicketyWrecked bug reports

Bug reports sent from inside the game with **LateJoinPlus** for R.E.P.O (LJ+ menu → Overview → **Send a bug report**). Each report is an issue here, with its log saved under `reports/`.

## What a report contains
- What the player wrote and picked (optional).
- LateJoinPlus and game versions, host or client, the level, the number of players, the language.
- The player's mod list with versions.
- LateJoinPlus's own log lines and the errors from that game session.

## What it never contains
- Chat.
- Other players' names or Steam IDs: they're replaced with "Player 2", "Player 3" and so on before anything leaves the player's PC, and the server strips Steam IDs, Windows user folders, IP addresses and email addresses again.
- The sender's own name, unless they ticked "Include my name".
- Block lists, history, notes, voice, or any file other than the game log.

Nothing is sent until the player presses **Send**, after seeing exactly what will be sent.

## Removing a report
If a report of yours should be removed, ask on the LateJoinPlus Discord (linked on its Thunderstore page) with the report id (it's in the report), and it will be deleted.

## Not for
Feature requests and general chat. This page is only for reports sent from the game: issues and comments are closed to everyone else, and reports are locked once they're sorted.
